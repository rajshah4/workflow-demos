🤖 deep_research_workflow.py
# Register sub-agent types (once) register_agent_if_absent("web_searcher", ...) register_agent_if_absent("fact_checker", ...) register_agent_if_absent("synthesizer", ...) # Create parent agent with workflow tool parent_agent = Agent( llm=LLM(model="gpt-4o-mini"), tools=[Tool(name=WorkflowToolSet.name)] ) # Send the task conversation = Conversation(agent=parent_agent) conversation.send_message( "Research deeply from multiple angles" ) # THE AGENT WRITES THE ORCHESTRATION result = conversation.run()
Agent wrote this code The skill guided the agent on HOW to structure the workflow. The agent decided which angles to research and which sub-agents to use.
The Skill Pattern The skill tells the agent: "Identify 4-6 research angles, use map_agents, use reduce_agent" The agent figures out: "For market size, I need: overview, tech, experts, stats, concerns"

What the agent wrote:

async def main(wf): angles = ["Market...", "Tech...", ...] market_data = await wf.map_agents( items=angles, subagent_type='web_searcher' ) verified = await wf.map_agents( items=market_data, subagent_type='fact_checker' ) return await wf.reduce_agent( items=verified, subagent_type='synthesizer' )
