The Code

# deep_research_manual.py - THE OLD WAY # This is what everyone writes today to build multi-agent systems # YOU define research angles RESEARCH_ANGLES = [ "Market overview and major players", "Technical developments", "Expert opinions", "Statistics", "Concerns" ] # YOU create the results list research_results = [] # =========================================== # YOU write the loop - Phase 1: Research # =========================================== for i, angle in enumerate(RESEARCH_ANGLES): # YOU create the conversation research_agent = create_research_agent(llm) conv = LocalConversation(agent=research_agent, workspace="/tmp") # YOU send the message conv.send_message(f"Research: {angle}") # YOU run it conv.run() # YOU extract the result result = conv.state.events[-1].content research_results.append(result) # YOU close the conversation conv.close() # =========================================== # YOU write the loop - Phase 2: Verification # =========================================== for angle, result in zip(RESEARCH_ANGLES, research_results): # ... another loop YOU write ... checker_agent = create_fact_checker(llm) conv = LocalConversation(agent=checker_agent, workspace="/tmp") conv.send_message(f"Verify: {result}") conv.run() verified_results.append(conv.state.events[-1].content) conv.close() # =========================================== # YOU aggregate manually - Phase 3: Synthesis # =========================================== synth_conv = Conversation(synthesizer) synth_conv.send_message(f"Combine: {verified_results}") final_report = synth_conv.run()
👤

Notice: YOU write every loop, create every conversation, extract every result. The agent is just a worker executing your instructions.

Problems With This Approach

  • 1

    Sequential by default — The loop runs one at a time. You have to explicitly parallelize if you want concurrency.

  • 2

    You control the loop — Not the agent. The agent is just a worker executing tasks you assign.

  • 3

    Every project repeats this — The orchestration code looks the same across projects. Only prompts change.

  • 4

    Fragile — Want to add a research angle? Modify the loop. Want to change aggregation? Modify the loop.

  • 5

    The agent doesn't learn — Each run, the agent starts fresh. It doesn't adapt its orchestration.

How It Flows

The Mental Model

You → Write for loop → Create Conversation → Send Message → Run Agent → Extract Result

You are the conductor. The agents are the musicians. You tell each when to play.
