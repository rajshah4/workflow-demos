The Code You Write

# deep_research_workflow.py - THE NEW WAY # ⚠️ This is the OpenHands SDK implementation, not Anthropic's # =========================================== # STEP 1: Register sub-agents (build the team) # =========================================== # Define what each role can do - done once register_agent_if_absent("web_searcher", create_web_searcher, "Searches the web") register_agent_if_absent("fact_checker", create_fact_checker, "Cross-checks claims") register_agent_if_absent("synthesizer", create_synthesizer, "Creates reports") # =========================================== # STEP 2: The skill (guides the agent) # =========================================== # This tells the agent WHEN and HOW to use workflows ORCHESTRATOR_SKILL = { "name": "orchestrator", "content": """ When asked to research deeply: 1. Identify 4-6 distinct research angles 2. Use wf.map_agents() to fan out research in parallel 3. Use wf.reduce_agent() to synthesize findings """ } # =========================================== # STEP 3: Create parent agent (hires the team lead) # =========================================== parent_agent = Agent( llm=LLM(model="gpt-4o-mini"), tools=[Tool(name=WorkflowToolSet.name)], # ← THE MAGIC agent_context=AgentContext(skills=[ORCHESTRATOR_SKILL]) ) # =========================================== # STEP 4: Send the task (the agent writes the rest) # =========================================== conversation = Conversation(agent=parent_agent) conversation.send_message("What is the AI coding assistant market size in 2024?") result = conversation.run()
🤖

The agent receives the task, uses the skill to decide on a workflow, and calls wf.map_agents() and wf.reduce_agent().

The Skill Pattern

The skill tells the agent when to use workflows and how to structure them. The agent figures out the specifics based on the question.

What the Agent Decides

Based on the question + skill, the agent picks research angles:

  • 1 Market overview and major players
  • 2 Technical developments and capabilities
  • 3 Expert opinions and analysis
  • 4 Statistics and market data
  • 5 Concerns and counterarguments

What the Agent Writes

# This is what the agent writes (you don't see this, the agent does it) async def main(wf): # The agent decided these angles based on the question angles = [ 'Market overview and major players', 'Technical capabilities', 'Expert opinions', 'Statistics and data', 'Concerns and debates' ] # Fan out to web_searcher agents in parallel market_data = await wf.map_agents( items=angles, subagent_type='web_searcher' ) # Cross-check with fact_checker agents verified = await wf.map_agents( items=market_data, subagent_type='fact_checker' ) # Synthesize into final report return await wf.reduce_agent( items=verified, subagent_type='synthesizer' )
