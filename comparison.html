Workflows vs Manual Orchestration

What YOU write vs what the AGENT writes for you

The Objective

"Research the AI coding assistant market from multiple angles, then synthesize a report"

Without Dynamic Workflows

You Write the Orchestration

# Define agent prompts prompts = { "market": "Research market trends...", "tech": "Research tech...", } # Create agents market_agent = Agent(llm, prompts["market"]) tech_agent = Agent(llm, prompts["tech"]) # Create conversations market_conv = Conversation(market_agent) tech_conv = Conversation(tech_agent) # Run SEQUENTIALLY market_conv.send_message("Research market") market_result = market_conv.run() tech_conv.send_message("Research tech") tech_result = tech_conv.run() # Aggregate yourself synth_conv = Conversation(synthesizer) synth_conv.send_message(f"Combine: {all_results}") report = synth_conv.run() # You wrote 25+ lines. Sequential. You control.
  • Define each agent's system prompt
  • Create each conversation
  • Manage sequential execution (wait for each)
  • Aggregate results yourself
  • Handle errors for each step

With Dynamic Workflows

You Write the Objective, Agent Writes the Loop

# You just give the objective conversation.send_message( "Research the AI coding assistant market" ) conversation.run() # Agent generates: async def main(wf): angles = ["market", "tech", "experts"] findings = await wf.map_agents( "researcher", [f"Research {a}" for a in angles], max_concurrency=3 ) return await wf.reduce_agent( "synthesizer", summarize(findings) )
  • Agent decides: which angles to research
  • Agent decides: how many parallel agents
  • Agent decides: concurrency level
  • Agent decides: how to aggregate results
  • Results stay in workflow (not main context)

How "workflow" Gets Triggered

SKILL: research_orchestrator
When asked to research deeply
write a Python workflow:
  (1) fan out web_searcher agents
  (2) cross-check with fact_checker
  (3) synthesize with reduce_agent

The agent has a skill that tells it when/how to use workflows. When the task benefits from parallel agents, the agent writes a workflow script using wf.map_agents(), wf.reduce_agent(), etc.

The Bottom Line

Manual Orchestration

  • You write the control flow
  • 25+ lines of code
  • Sequential execution
  • Results flood context
  • Manual error handling

Dynamic Workflows

  • Agent writes the control flow
  • 2 lines of your code
  • Parallel execution
  • Results isolated
  • Built-in checkpointing
Like LangChain's Deep Research: Manual orchestration where you define the pipeline. Dynamic workflows shift the orchestration burden to the agent.
